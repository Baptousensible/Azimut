# Décisions et hypothèses de l'audit

| # | Décision / hypothèse | Raison |
|---|---|---|
| D1 | Exécuteur de remplacement + faux `PySide6.QtCore` (hors code livré, `docs/AUDIT/outils/`). **Décision de départ, depuis dépassée** : pytest + PySide6 + ffmpeg + ExifTool réels sont installés et les suites réelles font foi (`CONSTATS.md` § H) ; l'exécuteur ne sert plus qu'à l'historique. | Pas de réseau **au départ** : ni pytest ni PySide6 installables. Mieux vaut une preuve partielle clairement étiquetée que des affirmations de mémoire. Les résultats ne remplacent pas pytest + Qt. |
| D2 | Pas de worktrees ni de sous-agents. **Depuis, des worktrees jetables** (`rapports_locaux/…`, supprimés après usage) rejouent un test sur l'état pré-correctif sans toucher l'arbre partagé ; les sous-agents restent inutilisés. | Aucun outil de sous-agent disponible **au départ** ; travail séquentiel sur une seule branche. La revue indépendante (`requesting-code-review`) reste à faire. |
| D3 | H-01/H-02 : fichiers supprimés de l'arbre sans commit. | Déjà exclus par `.gitignore` : l'archive a été produite hors Git. Les deux dossiers n'ont pas été ouverts. |
| D4 | DEDUP-002 : en suppression **définitive** seulement, revérifier le BLAKE2b complet de l'exemplaire à supprimer **et** du gardien avant chaque retrait, y compris entre deux suppressions d'un même groupe ; quarantaine et corbeille restent sur taille + mtime. | Le risque irréversible n'existe qu'en mode « delete » : en quarantaine/corbeille, la copie reste récupérable. Coût assumé : une relecture complète de l'exemplaire et du gardien à chaque suppression. Reste non couvert : réécriture entre le hachage et l'`unlink` (TOCTOU). Mesure et décision de non-option : D13. |
| D5 | SEC-001 : seules les lignes commençant par « - » échappent au contrôle « chemin absolu ». | Les appelants n'émettent que des lignes `-Option` ou des chemins absolus (lecture + tests). |
| D6 | I18N-002 : retirer les deux alias hors registre plutôt que filtrer le résultat. | Plus simple ; l'invariant « toute cible d'alias ∈ registre » est testé et protège les ajouts futurs. |
| D7 | D-02 : aligner la doc sur la CI (3.12) au lieu d'ajouter 3.11 à la CI. | Modifier la CI sans pouvoir l'exécuter est risqué. Recommandation conservée (CI-001). |
| D8 | D-03 : `PySide6-Essentials` + `PySide6-Addons` partout, bornés `<6.13` (valeur donnée par les consignes, AZ-C02). | Cohérence avec `requirements.txt`. Résolution `pip` non vérifiée hors ligne. |
| D9 | LOG-004 (0600) laissé tel quel. | Prudent pour préférences/journaux ; le changer pour les seuls exports est une décision produit. |
| D10 | Aucune modification Qt non testable (I18N-001, SEC-002) n'est appliquée. | Règle 1 : pas de « corrigé » sans preuve exécutée. |
| D11 | `THIRD_PARTY_NOTICES.md` ajouté comme ébauche. | Demandé par H-04 ; licences non revérifiables hors ligne, à valider. |
| D12 | Les 2 FAIL restants de l'exécuteur sont classés « environnement ». | Tests qui lancent un interpréteur neuf sans mon faux Qt. |
| D13 | DEDUP-002 : pas d'option pour désactiver la revérification en suppression définitive. | Mesure locale (8 copies de 96 Mio, cache chaud) : application médiane 2,75 s dont 2,69 s de hachage ; revérifier le gardien à chaque retrait ajoute 1,03 s (+62 %) par rapport à un hachage unique, soit ~1,6 s/Gio supprimé. Projection linéaire pour 10 copies de 10 Gio : ~2,4 min de surcoût sur ~6 min de vérification, dans une opération déjà confirmée deux fois. Le coût reste proportionnel et borné ; une option rouvrirait la perte irréversible que DEDUP-002 ferme. Si le coût gêne, optimiser le hachage (ctime, hash matériel) plutôt que le désactiver. |
